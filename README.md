# 🎛️ Envelope Rental - Plataforma de Reservas

Plataforma completa para gestionar reservas, clases y grabaciones de DJ.

## ⚡ INSTALACIÓN RÁPIDA

1. Node.js 16+ instalado
2. npm install
3. npm run dev

El servidor está en http://localhost:5000

## 📁 ESTRUCTURA

envelope-rental-app/
├── server/index.js (servidor principal)
├── package.json (dependencias)
├── .env (configuración)
└── README.md (este archivo)
